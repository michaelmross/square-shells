# Square Shells

Computational experiments on **deterministic multiplication coverage** in the square shell

```math
n^2 < m < (n+1)^2.
```

The basic observation is elementary but useful: there are exactly $n$ odd integers in this shell, and every odd composite $m$ has a prime factor $p\le n$. If the odd multiplication rows $p\le n$ are generated by Eratosthenes-style multiplication marking, then:

- an odd shell position hit by at least one irreducible row is composite;
- an odd shell position hit by no irreducible row is prime.

This repository records the computational phase of an investigation into how much prime information can be extracted from the **overlap geometry of multiplication rows**, without beginning from a primality test on the shell positions.

> **Status.** These computations are experiments and exact finite calculations, not a proof of a new prime-in-short-interval theorem. Later analytic work on product-truncated Möbius sums and Type I/II estimates is not yet represented by the code in this repository.

## 1. Multiplication depth and the overlap hierarchy

For an odd shell position $m$, let

```math
w(m)=\left\lvert\{p\le n:\ p\text{ is an irreducible odd multiplication row and }p\mid m\}\right\rvert.
```

Define the collision sums

```math
S_j(n)=\sum_m \binom{w(m)}{j}.
```

For odd $K$, ordinary Bonferroni gives

```math
U_K=S_1-S_2+S_3-\cdots+S_K,
```

an upper bound for the number of covered odd positions. Since the shell has exactly $n$ odd positions,

```math
H_K=n-U_K
```

is a deterministic lower bound on the number of uncovered positions ("certified holes").

The exact number of holes is

```math
H_{\mathrm{exact}}=\left\lvert\{m:w(m)=0\}\right\rvert,
```

which is also the exact number of primes in the shell.

The loss from truncating inclusion-exclusion at odd order $K$ is itself exact:

```math
U_K-|C|
=
\sum_{w\ge K+1}\left\lvert\{m:w(m)=w\}\right\rvert\binom{w-1}{K}.
```

So the finite-depth error is completely accounted for by high-multiplicity collisions.

## 2. Shifted polynomial majorants

The experiments also use a family of pointwise coverage majorants

```math
P_{K,r}(w)
=
1+
\frac{(w-1)\prod_{j=0}^{K-2}(w-r-j)}
     {\prod_{j=0}^{K-2}(r+j)},
\qquad K\text{ odd},\quad r\ge2.
```

For integer $w\ge1$,

```math
P_{K,r}(w)\ge1,
```

while $P_{K,r}(0)=0$. Expanding in the binomial basis,

```math
P_{K,r}(w)=\sum_{j=1}^K c_j\binom{w}{j},
```

gives a deterministic coverage bound

```math
L_{K,r}=\sum_{j=1}^K c_jS_j.
```

A shell is certified to contain a hole whenever

```math
L_{K,r}<n.
```

The ordinary Bonferroni bound is $r=2$.

Two low-order majorants found computationally are

```math
L_{3,3}=S_1-\frac56S_2+\frac12S_3,
```

and

```math
L_{5,3}
=
S_1-\frac{14}{15}S_2+\frac45S_3-\frac35S_4+\frac13S_5.
```

## 3. Main computational results

### Dense scan through $n=10^6$

The long shifted-hierarchy scan reached every shell through $n=1{,}000{,}000$.

At the endpoint:

| quantity | value |
|---|---:|
| $n$ | 1,000,000 |
| exact holes in the shell | 72,413 |
| maximum multiplication depth | 9 |
| $K=5,r=3$ bound / $n$ | 0.9472664 |
| $K=5,r=3$ certified holes | 52,733.6 |
| $K=7,r=2$ bound / $n$ | 0.927792 |
| $K=7,r=2$ certified holes | 72,208 |
| $K=9,r=2$ bound / $n$ | 0.927587 |
| $K=9,r=2$ certified holes | 72,413 |

Because the maximum depth at this shell is 9, ordinary Bonferroni at $K=9$ is exact.

The stable best shifts at the top of the scan are

```math
(K,r)=(3,4),(5,3),(7,2),(9,2),(11,2).
```

The cubic $r=3$ certificate first fails at

```math
n=24207.
```

No failure of $K=5,r=3$ was found through $10^6$; likewise the higher orders used in the scan remain successful.

**Checkpoint caveat.** `overnight_hierarchy.checkpoint.json` is marked `"history_complete": false` because the final v3 run was bootstrapped from a v2 scan at $n=247000$. The scan itself completed through $10^6$, but some cumulative pre-resume failure-count and worst-ratio aggregates cannot be reconstructed from the v3 checkpoint alone. The persisted first-failure information and sampled/event rows remain useful.

### Local windows at $n=10^6$

For the shell around $10^{12}$, applying the certificates to every contiguous local window gave:

| certificate | shortest uniformly certified window | consecutive integers |
|---|---:|---:|
| $K=5,r=3$ | 391 odd positions | 782 |
| $K=7,r=2$ | 207 odd positions | 414 |
| $K=9,r=2$ | 130 odd positions | 260 |

At $K=9$, the 260-integer threshold coincides with the actual longest prime gap in that shell.

For the $K=5,r=3$, $L=391$ experiment:

- main-term margin: about 20.2723 holes;
- worst passing window: weighted remainder $R\approx19.5390$, leaving a certificate of $0.7333$;
- the adjacent $L=390$ case fails narrowly, with $R\approx20.3538$ against a main margin of about 20.2205.

## 4. Parity-like cancellation

`parity_diagnostic.py` decomposes the local remainder by collision order.

For a median 391-position window at $n=10^6$,

```math
R\approx-0.2610,
```

but this small net value comes from large cancellation:

```math
R_{\text{odd }j}\approx+48.953,\qquad
R_{\text{even }j}\approx-49.214.
```

For the worst passing 391-position window,

```math
R\approx19.539,
```

with

```math
R_{\text{odd }j}\approx21.419,\qquad
R_{\text{even }j}\approx-1.880.
```

This was the first strong indication that dangerous local windows arise when the usual odd/even cancellation weakens.

## 5. Phase-scramble controls

`phase_scramble_test_v2.py` compares three models:

1. **genuine** — the actual square-shell phase vector;
2. **uniform** — each prime row gets an independent uniform phase modulo $p$;
3. **independent_square** — each row keeps the correct quadratic-residue marginal, but the common square anchor is destroyed.

At $n=10^6$, $K=5,r=3$, $L=391$, with 100 trials:

- genuine square shell: `max R = 19.538984`, no failing windows;
- uniform scrambles: mean `max R ≈ 125.1`, all 100 trials fail somewhere;
- independent-square scrambles: mean `max R ≈ 121.9`, all 100 trials fail somewhere.

The suppression is not peculiar to the single shell $n=10^6$. In a 41-shell genuine ensemble from $n=995000$ to $1005000$, the typical maximum remainder remains near 19; only 7 of 41 shells fail at the fixed test length $L=391$.

## 6. The product-cutoff experiment

The phase-scramble work led to the key arithmetic distinction between genuine and randomized row systems.

If distinct rows $p_1,\dots,p_j$ meet at a genuine shell position $m$, then

```math
d=p_1\cdots p_j\mid m<(n+1)^2.
```

Therefore every genuine intersection satisfies

```math
d<(n+1)^2.
```

Independent phase scrambles do not obey this constraint and can create formal coincidences with products far larger than the shell itself.

`high_product_collision_test.py` measures the weighted intersection mass by product range. In the 100-trial experiment:

- genuine shell: weighted mass from $d\ge(n+1)^2$ is exactly 0;
- uniform scrambles: mean impossible-product mass is about 105.86;
- independent-square scrambles: mean impossible-product mass is about 106.28.

For the genuine worst window, the weighted actual intersection mass was:

| product range | weighted mass |
|---|---:|
| $d\le n$ | +399.8 |
| $n<d\le n^2$ | -18.1333 |
| $n^2<d<(n+1)^2$ | +8.6 |
| $d\ge(n+1)^2$ | 0 |

This product cutoff became the main structural clue for the later analytic work.

## 7. Code guide

### Core coverage and hierarchy

#### `code/multiplication_coverage.py`

Base deterministic shell-coverage computation.

- constructs irreducible multiplication rows by multiplication marking;
- evaluates which odd positions are hit;
- uses no primality test on shell positions and no pre-supplied prime list.

This is the natural starting point for understanding the project.

#### `code/multiplication_overlap_hierarchy.py`

Computes $w(m)$, $S_j$, ordinary Bonferroni bounds, exact holes, and the depth histogram.

Examples:

```bash
python code/multiplication_overlap_hierarchy.py --n 10000

python code/multiplication_overlap_hierarchy.py \
  --start 2 --stop 10000 \
  --outdir overlap_out \
  --write-histogram --progress-every 500

python code/multiplication_overlap_hierarchy.py \
  --n 1000000 --max-order 13
```

#### `code/multiplication_overlap_hierarchy_v2.py`

Updated hierarchy driver with additional ways to specify the target shell (`--value`, `--shell-lo`) and faster marking/details used during later experiments.

### Majorants and dense scans

#### `code/multiplication_majorant_lp.py`

Solves a linear program for low-order pointwise majorants

```math
\sum_{j=1}^K c_j\binom{w}{j}\ge1.
```

Requires CSV input containing `n,S1,...,SK`. Numerical coefficients are rationalized and, when SymPy is available, the resulting polynomial is factored to look for a universal integer-$w$ proof.

Example:

```bash
python code/multiplication_majorant_lp.py \
  results/overlap_summary.csv \
  --order 3 --max-w 100
```

#### `code/overnight_shifted_hierarchy.py`

Dense scan of every shell in a requested range for the shifted family $P_{K,r}$.

#### `code/overnight_shifted_hierarchy_v2.py`

Intermediate long-run version used during the scan toward $10^6$.

#### `code/overnight_shifted_hierarchy_v3.py`

Recommended version for long scans. Adds checkpoint/resume support, transition logging, and atomic checkpoint writes.

Example:

```bash
python code/overnight_shifted_hierarchy_v3.py \
  --start 10001 --stop 1000000 \
  --orders 3,5,7,9,11 \
  --rmax 12 \
  --workers 2 \
  --write-every 1000 \
  --checkpoint-every 1000 \
  --heartbeat-every 10000 \
  --out overnight_hierarchy.csv
```

Resume:

```bash
python code/overnight_shifted_hierarchy_v3.py \
  --resume \
  --stop 1000000 \
  --orders 3,5,7,9,11 \
  --rmax 12 \
  --workers 2 \
  --out overnight_hierarchy.csv
```

### Main-term model

#### `code/main_term_optimizer.py`

Computes the unrestricted reciprocal-prime elementary symmetric sums

```math
e_j=\sum_{p_1<\cdots<p_j\le n}\frac{1}{p_1\cdots p_j}


and searches $(K,r)$ for the smallest model value

```math
M_{K,r}(n)=\sum_j c_je_j.
```

Examples:

```bash
python code/main_term_optimizer.py --n 1000000
python code/main_term_optimizer.py --n 1000000 --kmax 15 --rmax 8
```

This is an independence/main-term diagnostic; it does **not** impose the later-discovered product cutoff $p_1\cdots p_j<(n+1)^2$.

### Local remainder diagnostics

#### `code/parity_diagnostic.py`

For a chosen $n,K,r$, finds the shortest locally certifying window and decomposes the remainder into its collision-order contributions. Used to identify the large odd/even cancellation in typical windows.

#### `code/phase_scramble_test_v2.py`

Three-way control experiment comparing genuine square phases, independent uniform phases, and independent square-residue phases.

#### `code/nearby_square_ensemble.py`

Runs the same local-window diagnostic over nearby genuine square shells to test whether the behavior at one shell is exceptional or stable across scale.

#### `code/modulus_band_suppression.py`

Breaks the worst-window remainder into modulus/product scales. It was designed to locate which scales suppress the dangerous remainder in genuine shells relative to scrambled controls.

#### `code/high_product_collision_test.py`

Tests the product-geometry explanation directly by separating intersections according to the product

```math
d=p_1\cdots p_j.
```

This script established that scrambled controls acquire large weighted mass from products that are arithmetically impossible in a genuine square shell.

## 10. Reproducing a small run

A quick route through the main ideas is:

```bash
# 1. Compute the overlap hierarchy for one shell
python code/multiplication_overlap_hierarchy.py --n 10000

# 2. Generate hierarchy data over a modest range
python code/multiplication_overlap_hierarchy.py \
  --start 2 --stop 10000 \
  --outdir overlap_out --write-histogram

# 3. Search for a low-order pointwise majorant
python code/multiplication_majorant_lp.py \
  overlap_out/overlap_summary.csv \
  --order 3 --max-w 100

python code/overnight_shifted_hierarchy_v3.py \
  --start 10001 --stop 50000 \
  --orders 3,5,7,9 \
  --rmax 12 --workers 2 \
  --out trial_hierarchy.csv
```

The $n=10^6$ local-window and scramble diagnostics are substantially more expensive than these small examples.

## 11. Interpretation and limitations

A few points are easy to confuse:

- `exact_holes` is the number of uncovered odd positions in a **single square shell**, not $\pi(n)$.
- For example, `exact_holes = 72413` at $n=10^6$ means there are 72,413 primes in

```math
  10^{12}<m<(1{,}000{,}001)^2,
```

  not that $\pi(10^6)=72413$.
- A finite-$K$ certificate can fail even when a window contains many primes. Failure means the chosen majorant did not certify a hole; it does not mean the window is prime-free.
- The randomized phase experiments are controls, not models of prime distribution.
- The product cutoff is an exact arithmetic restriction in the genuine shell, but by itself it does not prove a short-interval prime theorem.

## 12. Development history

The code reflects the order in which the investigation developed:

1. deterministic shell coverage;
2. finite overlap / Bonferroni hierarchy;
3. LP-discovered shifted majorants;
4. dense scan of shifted certificates;
5. local-window remainder and parity diagnostics;
6. phase-scramble controls;
7. nearby genuine-shell controls;
8. modulus-band analysis;
9. discovery that formal scrambled intersections with

```math
   p_1\cdots p_j\ge(n+1)^2
```

   account for most of the dangerous excess remainder.

The last point motivated the later **product-truncated geometric main term** and the subsequent analytic investigation. Those later scripts and calculations are not yet part of this repository snapshot.
